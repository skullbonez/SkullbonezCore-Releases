# SkullbonezCore 2026.09.24.1 — marble runs, Director cameras and fullscreen

This release combines today's Minecraft editor and building update with the new
marble-run objects, Camera A/B Director mode, group selection, solar-scene fixes,
and remembered fullscreen setting. All changes are included on the source
repository's main branch.

## Download and run

Download **SkullbonezCore-2026.09.24.1-win-x64.zip**, extract the entire archive
into a writable folder, and run **SKULLBONEZ_CORE.exe**. Keep **SkullbonezData**
and the DLLs beside the executable. Open **Tutorial** for the guided walkthrough.

Requires 64-bit Windows and a DirectX 12-compatible graphics card. This is an
unsigned portable build. The included release manifest records the exact source
commit and file checksums.

## New in this update

- **Marble-run objects:** the Objects palette now includes a U channel built from
  five convex pieces, a funnel with a bottom opening, and dominoes.
- **Marble-run scene:** a ball drops through three floating channels, turning
  90 degrees between stages, then circles the funnel before falling through.
- **Drag selection:** in Edit mode, choose **Select [Q]** and drag a rectangle
  around objects. Hold **Ctrl** to add to the selection; Ctrl-click toggles an
  individual object. Choose **Move [W]** or **Rotate [E]** to transform the group.
  Undo/Redo applies to the whole gesture, and **Esc** cancels an active gesture.
- **Camera A/B and Director mode:** place two scene cameras, save them with the
  scene, and move smoothly between them using **Space**. Instructions are below.
- **Solar System and Slingshot fixes:** the authored starfield is preserved;
  camera flight slows near bodies, scene changes reset wheel speed boosts, and
  orbit/vertical movement follows the scene's authored up direction.
- **Fullscreen toggle:** **Fullscreen** sits at the far right of the top bar.
  It changes to **Windowed**, which restores the previous window size, position
  and maximized state. The choice is saved on exit and restored next launch.
  New installations start windowed.
- **Tools drawer:** releasing the opening click during its animation now ends
  the gesture correctly, keeping scrolling and controls responsive.

## Using the new camera mode

1. Open the Editor and enable **Edit scene**. If **Minecraft mode** is enabled,
   turn it off in **Controls**, then select the **Objects** tab.
2. Choose **Camera A** from the object palette and click the level to place it.
   The camera initially points in the current editor view direction. Use the
   editor's altitude control to raise its position.
3. Choose **Camera B** and place the second shot the same way. The colored
   frustums show where each camera is aiming while you edit.
4. **Save the scene** to keep both placements. Select and place either camera
   again if you want to reposition it.
5. Choose **Director** from the camera-mode dropdown in the top bar. It starts
   at Camera A. Press **Space** to travel to B over two seconds; press Space
   again to return to A. Camera frustums are hidden in the captured view.

## Included from today's earlier build

- Separate **Controls**, **Objects**, **Terrain** and **Material** editor tabs.
- **Minecraft mode** with walking, jumping and free flight. WASD moves; **F**
  switches flying/walking; **Space** rises or jumps; **Shift** descends in flight.
  Click the viewport to capture mouse-look and press **Esc** to release it.
- In Minecraft mode, **right-click** places and **left-click** removes a supported
  object. Keys **1–6** choose box sizes; the wheel adjusts placement height.
- Ground snapping, stacking from above or below, persistent Minecraft mode when
  changing object types, and placement preview on viewport hover.
- Group movement/rotation and undo/redo up to scene capacity: 4,000 objects by
  default, with an engine maximum of 8,192. Delete, Stack and Start sleeping
  controls help construct scenes.
- Terrain brushing stays in the Terrain tab. Replay solver snapshot reserve
  grows as needed within a shared 128 MiB ceiling.
