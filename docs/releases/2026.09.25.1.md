# SkullbonezCore 2026.09.25.1

This update adds left-hand number shortcuts and wheel zoom to Minecraft mode.
It also restores access to the existing selection and transform tools while
Minecraft mode remains enabled.

## Download and run

Download the Windows x64 ZIP from this release, extract the whole archive into
a writable folder, and run **SKULLBONEZ_CORE.exe** or **Launch SkullbonezCore.cmd**.
Keep **SkullbonezData** and the DLLs beside the executable. Requires 64-bit
Windows and a DirectX 12-compatible GPU and driver. This portable build is
unsigned. Optional Solver Lab comparison recordings are omitted.

The updated **SkullbonezCore-First-Time-User-Manual.pdf** is included in the ZIP
and available separately. **Tutorial** in the top bar opens the guided lessons.

## Minecraft controls: number keys now override the old shortcuts

1. Open **Editor > Controls**, enable **Edit scene** and **Minecraft mode**.
   Choose **Box** or another object in **Objects**. For practice, start with
   **New scene** or open **marble_run.scene.json**.
2. Move over the viewport to see the preview. Click once to capture mouse-look;
   that first click does not place anything. Then **left-click places** and
   **right-click removes** the targeted supported standalone object. **Esc**
   releases the mouse so you can use panels.
3. Scroll the **mouse wheel to zoom in/out**, including during captured
   mouse-look. **Ctrl + wheel** rotates the placement preview in 15-degree steps;
   **Shift + wheel** raises/lowers it. Scrolling over a panel still scrolls that
   panel when the mouse is released.
4. Use the number row with the left hand:

| Key | Action |
| --- | --- |
| **1** | **Move** tool; releases captured mouse-look and leaves placement. |
| **2** | **Rotate** tool; releases captured mouse-look and leaves placement. |
| **3** | **Scale** tool; releases captured mouse-look and leaves placement. |
| **4** | Turn the placement preview, or each selected standalone block, **90 degrees around world up**. |
| **5** | Snap the preview or selected standalone blocks to terrain ground. For the preview, clears height adjustment and bypasses stacking until the next placement. |
| **6** | Reset to the edited starting arrangement and clear the recorded timeline. Also works outside Minecraft mode in a scene. |

These keys replace the old Minecraft box-size presets. Keys 1–5 also take
priority over the water/terrain debug shortcuts in Minecraft mode. Key 6 replaces
the old transparent-physics shortcut; that display remains available through
the **Transparent** control in Physics.

## Edit existing blocks without leaving Minecraft mode

1. Press **1**, **2** or **3**, then click an existing block to select it.
2. Drag a Move arrow or plane handle, Rotate ring, or Scale handle. The usual
   **Q Select / W Move / E Rotate / R Scale** shortcuts still work after **Esc**
   releases mouse-look. During captured mouse-look, **WASD** moves the camera.
3. Press **4** for a quarter-turn or **5** for ground snap on the selection.
   **Ctrl+Z** undoes committed edits; **Ctrl+Y** or **Ctrl+Shift+Z** redoes them.
   **Esc** cancels an active gizmo drag. Quick turn/snap applies to editable
   standalone bodies; locked objects and linked assemblies are excluded.
4. Choose an object in **Objects** to return to placement. Enable **Static object**
   for fixed obstacles. Minecraft navigation still uses **F** to switch flying
   and walking, **Space** to rise/jump, and **Shift** to descend while flying.

Placed boxes and hulls now retain the preview's yaw even with **Terrain align**
off. The preview and committed body therefore agree on rotation.

## Reset and keep building

Leave editing and press **Play** to test the scene. Press **6** (or **Backspace**)
to restore the current authored starting poses and clear the simulation timeline.
The visible Scene button is now **Reset [6]**. Reset keeps editor changes made
before running, including unsaved placements and transforms; it does not reload
the last file from disk or save your work. Use **Editor > Controls > Save scene**
to keep the setup after reopening. Save a replay recording before resetting if
you want to retain that run. Reset and transform shortcuts do not act while a
text field or popup owns keyboard input.

## Camera Director controls have changed

Carried forward from 2026.09.25: **camera A/B placement has been removed**.
The Director now moves **one camera along a captured path**, with easing and
duration applied over the whole path, not separately at each waypoint.

1. Turn Minecraft mode off for ordinary camera navigation. Enable **Edit scene**
   and open **Camera**, beside **Replay** in the lower-left panel. The Camera tab
   is hidden outside Edit mode.
2. Hold right mouse and use **WASD** to move; release right mouse and click
   **Capture view** at two or more positions (up to 32).
3. Choose **Curve: Spline** or straight segments and **Linear / Ease in /
   Ease out / Ease in-out**. **Faster / Slower** changes the whole-path duration.
4. **Play path** starts playback; **Space** pauses/resumes and **Restart path**
   returns to the start. **B** temporarily grabs the camera. **Save path / Load
   path** writes/reads a separate `.shot.json` file; use Save path to retain it.

The previous release's crash-test ragdolls and sphere head colliders are also
included. Existing saved box-head snapshots retain their original physics.
