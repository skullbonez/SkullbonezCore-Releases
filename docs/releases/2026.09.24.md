# SkullbonezCore 2026.09.24 — Minecraft editor and building controls

Thank you for trying SkullbonezCore and sharing your feedback. This update focuses on constructing and editing scenes.

## Download and run

Download **SkullbonezCore-2026.09.24-win-x64.zip**, extract the entire folder, and run **Launch SkullbonezCore.cmd**. Keep the data folder and DLLs beside the executable. Open **Tutorial** in the app for the updated guided walkthrough.

Requires 64-bit Windows and a DirectX 12-compatible graphics card. This is an unsigned portable build.

## What's new

- **Separate editor tabs:** Controls holds scene actions, transforms and placement settings. Objects contains the object palette. Terrain and Material retain their own tabs. The tutorial follows the new layout.
- **Minecraft-style editing:** free flight plus walking and jumping. WASD moves; F switches flying/walking; Space rises or jumps; Shift descends while flying. Click the viewport to capture mouse-look and press Esc to release it.
- **Placement and removal:** right-click places the chosen object; left-click removes the targeted supported object. Keys 1–6 choose box sizes. The wheel adjusts placement height without camera zoom.
- **Snapping and stacking:** placement snaps to the ground or centers above a support. Stacking works from above, beside or below, including repeated clicks from underneath. Ground grid lines remain visual guides.
- **Persistent Minecraft mode:** changing the object type keeps the mode enabled. The placement wireframe appears as soon as the pointer enters the viewport, before mouse capture.
- **Multi-object editing:** Ctrl-click adds or removes objects from the selection. Move and Rotate operate on the whole selection around a shared centre, with grouped undo/redo. Selection now reaches scene capacity: 4,000 objects by default, up to the engine maximum of 8,192.
- **Building tools:** Delete/Del, Stack/K and Start sleeping help construct scenes. New scene starts with flat ground. Sleeping bodies can still wake from impacts; Delete applies to supported standalone objects.
- **Terrain input fix:** terrain brushing is restricted to the Terrain tab.
- **Replay memory:** the shared solver snapshot reserve ceiling increases from 8 MiB to 128 MiB, allocated as needed.
